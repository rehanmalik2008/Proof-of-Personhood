# Multi-point two-witness search — results

`scripts/two_witness_multipoint.mjs` (after-the-oracle.md, Task 1). The
single-point tool computes the Jacobian null space at **one** honest witness.
The rank of a non-linear R1CS Jacobian can vary across the solution manifold, so
one point is measure zero. This re-runs the exact same analysis — Jacobian null
space + exact non-linear re-verification of every direction against the full
R1CS — at **56 structurally diverse honest witnesses** of the deployed circuit
`wedge_mem_w8_d9_split` (4,309 constraints, O2).

## The 56 points (`build/multipoint/`, generated by `gen_input_multipoint.mjs`)

Every structural axis the Jacobian could depend on is varied:

| axis | values exercised |
|---|---|
| path shape | leftmost leaf (all `pathIndex=0`), rightmost (all `=7`), ascending, descending, alternating `0/7` and `1/4`, all-middle, single non-zero level (L0 / L4 / L8), max-depth (every level non-zero), random per level |
| sibling vectors | all-zero, all-one, all-`p−1`, random field elements, alternating `0 / p−1`, all-siblings-equal-to-`C` |
| `s` | random, `1`, `2`, `p−1` |
| `ctx` | random, `0`, `1`, `p−2` |
| `epochAction`, `epochTree` | random distinct, both `0`, both `1`, both large distinct, **equal**, large |
| `signalHash` | random, `0` (so `y = s`), `1` |

17 points are leftmost-leaf, 5 rightmost, 14 max-depth; the rest are mixed.

## Result

| quantity | value across all 56 points |
|---|---|
| null-space dimension (nullity) | **9 at every point** — one distinct value |
| directions killed by the non-linear re-check | 0 at every point |
| null-space directions that move a **public output** (`main.N`, `main.y`) | **0 at every point** |
| largest null-space entry on any public column, over all points | **0** (exact) |
| every null-space carrier is an `IsZero` `inv` hint | **yes, at every point** |

### The support does move — and it moves exactly as the mechanism predicts

There are 13 distinct null-space *support sets* across the 56 points, one per
`pathIndex` pattern. At each Merkle level `i` the single freed hint is
`main.mk.eq[i][pathIndex[i]].isz.inv` — the `IsZero` inverse hint of the
comparator for the slot that `pathIndex[i]` selects, whose comparator input is
`0`. Checked mechanically: **0 mismatches** between the freed hint's slot and
`pathIndex[i]`, over all 56 × 9 = 504 (level, point) pairs.

| path shape | freed hints (example) |
|---|---|
| all `pathIndex = 0` (deployed) | `eq[0][0] … eq[8][0]` |
| all `pathIndex = 7` | `eq[0][7] … eq[8][7]` |
| ascending | `eq[0][0] eq[1][1] eq[2][2] … eq[7][7] eq[8][0]` |
| max-depth (`1,2,3,4,5,6,7,1,2`) | `eq[0][1] eq[1][2] … eq[6][7] eq[7][1] eq[8][2]` |

This is the well-known benign internal freedom of `IsZero` relocating with the
witness, not a change in the *amount* of freedom. Nullity is invariant; only
*which* nine columns carry it changes. Task 3 (`taint_iszero.mjs`) proves each
of these freedoms benign.

### The "spectrum" question, answered for an exact field computation

"Singular-value spectrum" is a real/complex-analysis notion; the R1CS Jacobian
here is a matrix over the BN254 scalar field and its rank is **exact** — a
column is in the span or it is not, there is no "nearly zero" singular value,
and a floating-point SVD of entries whose balanced magnitude is ≈ 2²⁵³ (the
hash-output coefficients) would be numerical noise. The finite-field analogue of
a near-degenerate determination is a pivot that is non-zero only because of a
specific witness value. The decisive test for that is multi-point stability of
the exact rank, which is what this run provides, plus: **every one of the nine
freed columns has no non-zero entry in any Jacobian row** — an exact zero column
(the run reports this per carrier as `no-direct-pivot`) — and every other column
is a pivot at every one of the 56 points. There is no marginal determination
anywhere in the system.

## Quantified claim for the paper

> No second witness with a non-zero linear component was found at **56
> structurally diverse honest witnesses**, across the full R1CS with exact
> non-linear re-verification of every null-space direction. The null-space
> dimension is a stable **9** at every point; all nine directions are `IsZero`
> inverse hints, proven benign in `taint_iszero.md`; none has any component on
> any public output at any point.
>
> **Bound (unchanged):** a second witness reachable only by a large non-linear
> jump with zero linear component is outside this search. Multi-point probing
> removes the "measure-zero, single point" caveat; it does not remove this one.

If multi-point probing had found a direction moving a public output at any
point, that would have been a real soundness bug in the deployed circuit,
reported at the top of the paper (after-the-oracle.md, Falsification 1). It did
not. If the null-space dimension had varied across points, every prior
single-point "no second witness" claim would have needed requalification
(Falsification 2). It did not.
